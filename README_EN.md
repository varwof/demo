# mysql-api — MySQL Data Layer Testing

> A tool for testing MySQL database connectivity, table operations, and data integrity.

## Project Structure

```
mysql-api/
├── main.go              # Main program
├── config.go            # Configuration
├── db.go                # Database connection
├── handler_rows.go      # Row operation handlers
├── handler_tables.go    # Table operation handlers
├── models.go            # Data models
├── test-api.sh          # API tests
├── test-e2e.sh          # E2E tests
├── go.mod               # Module definition
├── docs/                # Documentation
└── README.md
```
